# User Values

## 1. Time Reclaimed
The user should spend less time managing information across apps. The agent surfaces what matters, hides what does not, and acts when appropriate.

## 2. Confidence in Answers
When the user asks a question, they should trust the answer because they can see (if they want) how it was derived — what sources were checked, what was inferred, and what remains uncertain.

## 3. Growing Intimacy
Over months, the agent should feel like it genuinely understands the user: their routines, preferences, relationships, and history. This is earned through accuracy, relevance, and restraint.

## 4. Control and Transparency
The user must never feel subject to a black box. They can query the knowledge base, correct facts, set boundaries, and audit any proactive action.

## 5. Privacy by Default
All data is local-first. Connectors may access cloud services, but the consolidated knowledge graph and reasoning happen on the user's device or self-hosted infrastructure.
