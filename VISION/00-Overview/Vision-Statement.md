# Vision Statement

## The Agent That Knows You

Build a persistent, personal intelligence that lives alongside you — not a chatbot you query and forget, but a reasoning companion that accumulates knowledge about your life, learns your preferences, connects to your services, and becomes more useful the longer you use it.

## Core Premise

Most AI tools today are stateless. You ask a question, get an answer, and the context evaporates. The next session starts from zero. This project inverts that model: **the agent is stateful, persistent, and ever-learning.**

It should know:
- Where you have been and when
- What you like, dislike, and have explicitly rejected
- What is in your calendar, inbox, photo library, and home
- How to reason across disconnected facts to answer questions no single service can answer alone
- When to be proactive — to remind, suggest, or act on your behalf

## Guiding Principles

1. **Persistence over ephemerality** — Every interaction, fact, and preference is stored, versioned, and retrievable.
2. **Implicit learning** — The agent observes, generalizes, and adjusts without requiring explicit training.
3. **User sovereignty** — You can inspect, edit, and delete anything it knows. The knowledge base is yours.
4. **Thoroughness** — When answering, it investigates all available avenues rather than settling on the first plausible answer.
5. **Proactivity** — As confidence in its model of you grows, it should anticipate needs rather than only respond to prompts.
6. **Openness** — OpenAI-compatible API endpoint for all LLM needs; pluggable connectors for services.

## What It Is Not

- It is not a generic search engine.
- It is not a hard-coded automation tool (IFTTT-style).
- It is not a surveillance system — all data stays local unless explicitly configured otherwise.
- It is not a social network or multi-user platform (initially).
