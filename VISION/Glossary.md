# Glossary

## Agent
The core software system described in this vision. A persistent, personal intelligence that accumulates knowledge, reasons, and acts on behalf of the user.

## Connector
A plugin module that bridges the agent with an external service (email, calendar, photos, etc.). Connectors read data, normalize it, and optionally write back.

## Core Agent
The orchestration layer that receives user input, maintains context, routes to subsystems, and streams responses.

## Entity
A node in the Knowledge Graph representing a real-world thing: person, place, event, object, concept.

## Evidence
A piece of data gathered during an investigation, from any source (Knowledge Graph, connector, web search, inference).

## Extracted Fact
A normalized, structured piece of information extracted from raw service data, ready for insertion into the Knowledge Graph.

## Fact
A directed, temporal relationship between entities in the Knowledge Graph. Contains subject, predicate, object, temporal bounds, confidence, and provenance.

## Hypothesis
A testable claim generated by the Reasoning Engine during an investigation. Evaluated against gathered evidence.

## Investigation
A structured query session conducted by the Reasoning Engine. Contains hypotheses, evidence, and a final synthesis.

## Knowledge Graph
The persistent graph database storing entities, facts, preferences, and sources. The agent's long-term memory.

## Local-First
An architecture principle where all data processing and storage happens on the user's device by default, with no cloud intermediary.

## Normalization
The process of converting raw, heterogeneous service data into a common schema of extracted facts.

## Object Re-Identification
The process of matching the same physical object across different video frames or camera angles using visual embeddings.

## Pattern
A recurring sequence or correlation learned from user behavior, stored in the Knowledge Graph to enable proactive suggestions.

## Preference
A user-specific setting or learned behavior stored in the Knowledge Graph with confidence scoring, used to modulate agent behavior.

## Proactive Agent
The subsystem that monitors events, recognizes patterns, predicts needs, and initiates actions without explicit user prompts.

## Provenance
The source and history of a fact: where it came from, when it was extracted, and how reliable the source is.

## Reasoning Engine
The subsystem that plans and executes multi-step investigations for complex queries, gathering evidence and synthesizing answers.

## Source
The origin of a fact or piece of evidence: a connector, a user edit, an inference, or an interaction.

## Spatial Memory
The subsystem that tracks the physical locations of objects over time using camera feeds and object detection.

## Temporal Bounds
The time period during which a fact is true. Facts can have `valid_from`, `valid_until`, or be timeless.

## Tool Registry
The dynamic registry of available tools (functions) that the LLM can invoke, including Knowledge Graph queries, connector actions, and reasoning invocations.

## Vision Tracker
The subsystem that processes camera feeds, detects objects, extracts embeddings, and maintains spatial memory.
